# 青芽・貪吃蛇

使用星泉（AquariusLang）製作的小花園貪吃蛇。遊戲程式、規則、函式呼叫、自訂變數、函式名稱及畫面文字皆使用繁體中文。桌面與網頁執行同一份編譯位元碼。

## 開始玩

在本專案目錄執行：

```powershell
.\啟動網頁.ps1
```

啟動腳本使用 Node.js 提供靜態檔案。使用支援圖形加速與 WebGPU 的瀏覽器開啟 <http://localhost:8080>。請透過本機伺服器或 HTTPS 提供 `web` 資料夾；直接雙擊網頁檔無法載入模組與圖形資源。網頁的執行階段與相依套件均已隨編譯結果封裝，沒有外部 CDN。

| 操作 | 功能 |
| --- | --- |
| 方向鍵、畫面方向按鈕 | 轉彎；最多預先保留兩次合法轉向 |
| 空白鍵、輸入鍵、主要按鈕 | 開始、暫停、繼續，或結束後再玩一次 |
| 重新開始按鈕 | 回到準備畫面，可重新選擇模式 |
| `W／A／S／D` | 上、左、下、右移動；畫面提示以方向鍵為主 |
| `R` | 回到準備畫面 |

吃一顆果實得十分，蛇身長一節；撞到自己的身體會結束。填滿全部四百格即獲勝。悠閒、標準、極速各有不同初始步調，吃果後逐步加速。撞牆與穿牆模式各自保存紀錄，共六組最高分。開始後鎖定模式，重新開始後可調整。

手機直式顯示完整棋盤、分數與方向按鈕；桌面使用棋盤與操作欄的並排版面。離開分頁造成超過六百毫秒的更新停頓時，遊戲自動暫停。

瀏覽器紀錄存在該網站來源的 IndexedDB，重新載入仍會保留。更換連接埠、網站網址、瀏覽器資料或使用無痕模式會有不同的紀錄。桌面使用星泉儲存庫的應用程式資料區；桌面與瀏覽器紀錄各自保存。

## 編譯

```powershell
.\建置.ps1

# 使用指定的編譯器位置
.\建置.ps1 -編譯器 '完整路徑\aqua.exe'
```

預設從 `C:\OfficialProjects\AquariusLangTW\dist\releases` 選擇最新的正式套件。參考與實際使用的版本：本機提交 `99d25fa`（2026 年 10 月 8 日），正式套件 `AquariusCompiler-win-x64-20261008-203849-ad895d0f`。

建置腳本先編譯並執行規則驗證，再以原版 AquariusLang 編譯器產生 `貪吃蛇.bottle`，最後從這份套件輸出相對的 `./web`。另在本專案的輸出外殼套用繁體中文語言標記、標題、錯誤提示與輸入輔助標籤；遊戲邏輯未使用 JavaScript 重寫。

等效核心指令如下：

```powershell
& '完整路徑\aqua.exe' build 貪吃蛇.aqua 中文介面.aqua 遊戲規則.aqua --root . -o 貪吃蛇.bottle
& '完整路徑\aqua.exe' build 貪吃蛇.bottle --target web -o ./web
& '完整路徑\aqua.exe' run 貪吃蛇.bottle
```

`C:\OfficialProjects\AquariusLangTW` 僅供讀取與執行其既有編譯器，未修改、更新或重新建置原專案。

## 繁體中文介面與目前語言限制

所有自行宣告的星泉識別名稱與函式呼叫均為繁體中文，包括原生繪圖及儲存函式，如 `畫.矩形`、`畫.文字`、`儲存庫.讀取`。

目前星泉原生 API 的模組名稱 `Processing`、`Storage`，渲染器字串 `P2D`，視窗與輸入屬性 `width`、`height`、`mouseX`、`mouseY`、`keyCode`，以及事件字串尚無繁體中文別名。這些不能改名的協定值集中在 `中文介面.aqua`；遊戲透過 `介面.視窗寬度()`、`介面.註冊點擊()` 等中文入口使用。未擅自修改語言專案來加入別名。因此原始碼並非完全不含英文字母，這是既有語言的限制。

`.aqua` 副檔名與倍精度數值後綴 `d` 也是編譯器要求的語法。儲存鍵採數字識別碼，符合原生儲存庫的英數字限制。

## 驗證

規則驗證共 236 項，涵蓋移動、暫停、反向阻擋、快速轉彎、身體碰撞、即將離開的尾巴格、四個穿牆方向、最後一格勝利、果實位置與速度下限。

實際桌面 VM 已執行並擷取畫面。瀏覽器驗證共 16 項，涵蓋正式網頁自動啟動、中文文字及圖形渲染、鍵盤與按鈕、六模式選擇、結束重玩、成長得分、紀錄重載、手機版面、暫停縮放、停頓自動暫停與資源釋放。

```powershell
# 使用參考專案已安裝的 Playwright，以及本機 Chrome
node .\網頁驗證.mjs
```

此工具只讀取參考專案的既有測試相依套件，使用暫時的本機連接埠與獨立瀏覽器測試資料。報告及截圖寫入本專案的 `驗證結果`。需要另指定參考專案或瀏覽器時，可設定 `AQUARIUS_REFERENCE` 或 `AQUARIUS_BROWSER` 環境變數。
